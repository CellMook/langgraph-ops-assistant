## 3. 通俗解释与精确技术定义

**人话**：面试不是让你背架构图，而是让你证明三件事——**你做的东西解决了真问题**、**你知道它的边界**、**你能改动它**。

**60 秒项目介绍模板（背下来，再用自己的话讲）**：

> 我做了一个经营数据分析助手：用户用自然语言问"九月比八月销售额变化多少、按地区分解"，系统会先解析口径，再检索指标定义与退款归属的知识库，然后查 SQLite，用程序算出差额与占比，生成一份带来源的 Markdown 报告，**停下来等人工审批**，批准后才落盘。
> 关键设计是**数字全部由程序计算，模型只做可选润色且不允许出现数字**——所以没有 API Key 也能跑通全链路，模型挂了也不影响出数。
> 工程上用 LangGraph 做固定工作流而不是让模型自由选工具，因为业务口径要求可审计、可复现；同时保留了 `create_agent` + 6 个工具的 Agent 路线做对比。
> 目前我验证了确定性路径的测试与评估脚本，但受限于环境没有跑过真实模型调用，这一点我在 `docs/verification.md` 里写清楚了。

**为什么这个介绍有效**：有业务问题、有技术选择、有取舍理由、有诚实的边界。

### 5.2 三条失败路径的命令

```powershell
cd .\ops-assistant

# 失败 1：缺年份 -> 澄清（不是报错）
uv run python scripts/run_cli.py -q "九月销售额是多少？"

# 失败 2：非法月份 -> 澄清 / 可读错误
uv run python scripts/run_cli.py -q "2026 年 13 月销售额比 12 月变化多少？"

# 失败 3：拒绝审批 -> 不落盘
uv run python scripts/run_cli.py -q "2026 年九月销售额比八月变化多少？按地区分解差额。" 
uv run python scripts/run_cli.py --list-threads
uv run python scripts/run_cli.py --thread-id <上一步的 thread_id> --resume reject
```

再加两条"加分项"失败路径：

```powershell
# 失败 4：资料不足（知识库没有这个词）
uv run python scripts/run_cli.py -q "2026 年 9 月销售额口径是什么？量子退火怎么算？"

# 失败 5：预算耗尽（临时调小）
$env:OPS_MAX_STEPS = "2"
uv run python scripts/run_cli.py -q "2026 年九月销售额比八月变化多少？按地区分解差额。"
Remove-Item Env:\OPS_MAX_STEPS
```

## 8. 失败与边界实验（面试模拟）

让同学/朋友按下面追问，你只允许看代码回答，不许背稿：

1. "中断后节点会重跑，你怎么保证不重复写文件？" → 副作用集中在 `export`，固定文件名 + 原子写 + 无中断时直接返回既有结果。
2. "为什么不用 Agent 让模型自己选工具？" → 口径要可审计；Agent 路线保留做对比，但不是主链路。
3. "上期是 0，变化率怎么算？" → `None` + `base_zero` + 文字说明，不编造百分比。
4. "无记录和真零怎么区分？" → `has_orders` 标志 + gross/refund 关系 + 报告边界小节。
5. "检索为什么用哈希向量？" → 离线可复现、零依赖；代价是词面匹配，同义改写会漏（已写进限制）。
6. "模型编造引用怎么办？" → 引用必须是本次命中的 `chunk_id`，否则回退模板。
7. "并发两个请求会怎样？" → 单 worker + 运行时锁；跨进程并发是已知限制。
8. "你怎么证明它是对的？" → 确定性测试 + 独立标准答案交叉验证；模型行为未验证，并如实说明。

## 10. 复盘问题与参考答案、下一步

**Q1：这个项目最难的地方是什么？**
A：不是调通框架，而是**让数字可追溯**：把"退款算哪个月""零基数""无记录 vs 真零"这些口径写成代码 + 测试 + 报告文字三处一致。

**Q2：如果给你两周继续做，你做什么？**
A：①用真实 embedding 替换哈希向量并做召回评估；②把 `sources` 改为 reducer 消除静默丢来源风险；③补并发审批的幂等键与锁；④接 LangSmith 做追踪（本地日志保留）。按"风险 × 收益"排序，不是按"看起来酷"。

**Q3：你怎么看"AI 应用工程师"这个岗位？**
A：核心不是会调 API，而是能把不确定的模型放进确定的工程约束里：可验证、可回滚、可解释、成本可控。这个项目就是我的一次练习。

**Q4：有什么你没做但应该做的？**
A：真实模型的行为评估（工具序列、答案忠实度）、并发与多用户隔离、真实数据接入与权限。它们都需要真实环境与时间，我在限制文档里列了。
