# 地区编码与范围说明（演示口径）

> 本文件是演示项目「经营数据分析助手」的知识库文档之一，**地区划分为演示口径**，不等同于官方行政区划。数据范围 2025-01 至 2026-09（共 21 个月）。

## 1. 五个地区与编码

| region_id | region_name | 演示口径覆盖范围 |
| --- | --- | --- |
| R_EAST | 华东 | 上海、江苏、浙江、安徽 |
| R_NORTH | 华北 | 北京、天津、河北、山西、内蒙古 |
| R_SOUTH | 华南 | 广东、广西、海南、福建 |
| R_SW | 西南 | 四川、重庆、云南、贵州、西藏 |
| R_NE | 东北 | 辽宁、吉林、黑龙江 |

## 2. “华东”包含哪些省份

- 在**本项目演示口径**下，华东（`R_EAST`）包含上海、江苏、浙江、安徽四地。
- 该映射与官方七大区划分不完全一致：真实业务中福建有时归华东、山东有时归华北；本项目固定使用第 1 节的映射，回答时必须声明“演示口径”。
- 查询时地区名“华东”与编码“R_EAST”都可用；工具层匹配到名称或编码后，统一按 `region_id` 过滤，避免同名歧义。

## 3. 地区表字段

- 地区表共 5 行：`region_id`（主键）、`region_name`（唯一）、`manager`（演示经理姓名）。
- `manager` 只用于展示，不参与指标计算；`orders.region_id` 外键引用地区表，因此订单一定归属某个地区。
- 地区粒度是“大区”，**不能下钻到省份或城市**；问“江苏省卖得怎么样”只能回答华东整体并说明粒度限制。

## 4. 地区维度的边界事实

- **无记录**：R_NE 东北在 2025-09、2026-08 没有任何订单，应写“无记录”，不能写“销售额 0”。
- **真零**：R_SW 西南在 2026-09 有订单，但已批准退款冲抵了全部毛销售额，净额为 0。
- **负净额**：2026-03 存在某地区退款大于毛销售额的情况，按正常口径展示负值。
- **差额分解**：2026-09 对比 2026-08 时，5 个地区的差额之和必须等于总差额，报告需给出校验行。

## 5. 地区类问题的回答要点

- “那华东呢？”——沿用上一轮的时间范围，只把地区过滤为 `R_EAST`，并在报告中写明过滤条件，不要重新猜月份。
- “哪些地区下降了？”——必须逐地区对比本期与上期净额，不能只看总额；下降原因只能写“可能相关，需进一步验证”。
- 地区名无法识别、但句子里出现“地区 / 大区”时，应向用户澄清可用地区列表，不要自行猜测或忽略该条件。

## 6. 已知缺口与限制

- 只有 5 个大区，无法做省份、城市或门店级分析。
- 不支持渠道维度分析：`orders.channel` 只在订单表留档（线下 / 天猫 / 京东 / 抖音），分析工具不暴露该维度。
- 演示数据由固定随机种子生成，地区间差异是构造出来的，不能当作真实经营结论。
