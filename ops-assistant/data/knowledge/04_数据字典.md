# 数据字典（演示口径）

> 本文件是演示项目「经营数据分析助手」的知识库文档之一，**全部为演示口径**。数据库为 SQLite，4 张表；金额一律整数「分」；日期一律 `YYYY-MM-DD` 文本；数据范围 2025-01 至 2026-09，固定随机种子 20260901 保证可复现。

## 1. 表与索引清单

- 四张表：`regions`（地区，5 行）、`products`（商品，12 行）、`orders`（订单，事实表）、`refunds`（退款，事实表）。
- 四个索引：`idx_orders_date`、`idx_orders_region`、`idx_refunds_date`、`idx_refunds_status`。
- 外键已开启（`PRAGMA foreign_keys = ON`），`orders.region_id`、`orders.product_id`、`refunds.order_id` 都是有效引用。

## 2. regions 地区表

| 字段 | 类型 | 约束 | 含义 |
| --- | --- | --- | --- |
| region_id | TEXT | 主键 | 地区编码，如 `R_EAST` |
| region_name | TEXT | 非空、唯一 | 地区名，如 `华东` |
| manager | TEXT | 非空 | 演示经理姓名，仅展示 |

## 3. products 商品表

| 字段 | 类型 | 约束 | 含义 |
| --- | --- | --- | --- |
| product_id | TEXT | 主键 | 商品编码 |
| product_name | TEXT | 非空 | 商品名 |
| category | TEXT | 非空 | 品类：数码 / 家居 / 服饰 / 食品 |
| unit_price_cents | INTEGER | > 0 | 目录价（分），范围 1999～19999 |

## 4. orders 订单表

| 字段 | 类型 | 约束 | 含义 |
| --- | --- | --- | --- |
| order_id | TEXT | 主键 | 订单编号 |
| order_date | TEXT | 非空 | 下单日期 `YYYY-MM-DD` |
| region_id | TEXT | 外键 regions | 所属地区 |
| product_id | TEXT | 外键 products | 商品 |
| quantity | INTEGER | > 0 | 数量，演示值 1～8 |
| unit_price_cents | INTEGER | > 0 | **成交**单价 = 目录价 × 0.9～1.1，四舍五入到分 |
| channel | TEXT | 非空 | 线下 / 天猫 / 京东 / 抖音；**仅存不分析** |

## 5. refunds 退款表

| 字段 | 类型 | 约束 | 含义 |
| --- | --- | --- | --- |
| refund_id | TEXT | 主键 | 退款单号 |
| order_id | TEXT | 外键 orders | 原订单 |
| refund_date | TEXT | 非空 | 退款日期 = 下单日 + 0～40 天 |
| amount_cents | INTEGER | > 0 | 退款金额（分） |
| reason | TEXT | 非空 | 退款原因，仅展示 |
| status | TEXT | IN 三值 | approved / pending / rejected |

## 6. 单位、时间与生成规则

- 所有金额以“分”存储：1 元 = 100 分；展示时再换算成元或万元，禁止用浮点数存钱。
- 月份由日期前 7 位得到；退款归属月取 `refund_date` 的月份，不取订单月份。
- 生成规则：每月每地区 6～14 笔订单；退款概率 8%；状态权重 approved 0.7 / pending 0.2 / rejected 0.1。
- 标准答案由独立脚本 `compute_ground_truth.py` 用原生 SQL 生成，不 import 项目查询层，避免循环验证。

## 7. 字段使用限制与已知缺口

- `channel` 字段存在但**分析工具不支持渠道维度**；回答“按渠道”类问题必须明确说明不支持，而不是静默忽略。
- 商品表没有成本字段，无法计算毛利；只有销售额与退款额两类指标。
- 没有客户表、库存表、支付流水表；无法做用户分层、库存周转或支付对账。
- `2025-01` 全月无订单；东北 2025-09、2026-08 无订单；商品 P_012 在 2026-05 无订单（商品维度零记录）；这些是“无记录”，不是“0 销售额”。
