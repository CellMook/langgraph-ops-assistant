# 指标口径说明（演示口径）

> 本文件是演示项目「经营数据分析助手」的知识库文档之一。**以下全部为演示口径**，不代表任何公司真实财务制度；数据范围固定为 2025-01 至 2026-09（共 21 个月）。

## 1. 毛销售额（gross）怎么算

公式：`毛销售额 = Σ(orders.quantity × orders.unit_price_cents)`，按 `order_date` 所在月份归集，单位为**分**。

- 必须使用订单成交单价 `unit_price_cents`，不能使用商品目录价 `products.unit_price_cents`；地区折扣已体现在订单价里。
- 日期字段是 `YYYY-MM-DD` 文本，统计月份取前 7 位（`YYYY-MM`）。
- 示例：某月两笔订单分别 2 件 × 1299 分、1 件 × 5999 分，则毛销售额 = 2598 + 5999 = 8597 分（85.97 元）。

## 2. 退款额（refund）怎么算

公式：`退款额 = Σ(refunds.amount_cents)`，条件为 `refunds.status = 'approved'` 且 `refund_date` 所在月等于统计月。

- 只有 `approved`（已批准）计入；`pending`（待处理）与 `rejected`（已拒绝）不计入。
- 退款按**退款发生月**归集，不按原订单月；跨月退款会降低退款发生月的净销售额。
- 状态字段只有三个取值：`approved`、`pending`、`rejected`。

## 3. 净销售额（net）是默认口径

公式：`净销售额 = 毛销售额 − 退款额`，单位为分，允许为负数。

- 用户问“销售额”时默认回答**净销售额**，并在报告中写明“已扣除已批准退款”。
- 若用户明确问“退款前销售额 / GMV / 未扣退款”，则对应毛销售额，不能与净销售额混用。
- 自检恒等式：`net_cents = gross_cents - refund_cents`，三者都是整数分。

## 4. 差额、变化率与零基数

- 差额：`delta = 本期净销售额 − 上期净销售额`，单位为分。
- 变化率：`pct_change = delta / 上期净销售额`（分母为前一期净额，按项目口径保留符号）；上期为 0 时变化率**无定义**，返回空值并写“基期为 0，变化率无定义”，不得写成 ∞ 或 100%。
- 地区差额分解：`地区差额 = 该地区本期净额 − 该地区上期净额`；各地区差额之和必须等于总差额，报告需给出合计校验行。

## 5. 单位与展示

- 计算全程使用**整数分**；展示默认换算为元（除以 100，保留 2 位小数）。
- 用户偏好万元时除以 10000，保留 2 位小数，例如 1234567 分 → 12345.67 元 → 1.23 万元。
- 负号写在数字前，例如 -1,234.56 元；报告中必须写明单位，禁止分与元混用。

## 6. 数据范围与已知缺口

- 数据范围：2025-01 至 2026-09；其中 2025-01 全月无订单，属于“**无记录**”，不是“销售额为 0”。
- 地区维度：5 个地区（R_EAST 华东、R_NORTH 华北、R_SOUTH 华南、R_SW 西南、R_NE 东北）；商品维度：12 个商品、4 个品类（数码、家居、服饰、食品），其中商品 P_012 在 2026-05 无订单（商品维度零记录）。
- **不支持按渠道分析**：`orders.channel` 字段虽然存在，但分析工具只支持 region / product / month 三个维度，问“渠道”时应明确说明不支持，不能静默忽略。
- 无记录、真零（有订单但净额为 0）、负净额、零基数必须分别表述，不能都简写成 0。
